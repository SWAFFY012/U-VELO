# U-VELO

Многостраничный сайт «Ю-Вело»: аренда, покупка и ремонт электровелосипедов.

## Запуск

Требуется Node.js 24 и npm.

```sh
cd site
npm ci
npm run dev
```

Сайт доступен на http://localhost:3000.

## Проверки и сборка

```sh
cd site
npm run lint
npm test
npm run build
npm start
```

## Структура

- `site/` — приложение Next.js, страницы, компоненты, API заявок и подготовленные фотографии.
- `ChatExport_Gor Aris/photos/` — исходные фотографии и визуальные материалы.
- PNG в корне — исходный объёмный логотип.

Настройки уведомлений и хранения заявок описаны в `site/.env.example`.
Тарифы и условия обновлены по скриншотам Авито; источники и оставшиеся уточнения — в `site/docs/avito-data.md`. Дизайн описан в `site/docs/design.md`.

Файлы окружения с ключами, заявки, зависимости и результаты сборки исключены из репозитория.
