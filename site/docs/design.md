# Ю-Вело — дизайн и структура сайта

Источник требований: договор на разработку сайта-каталога (ТЗ, разделы 2.1–2.2) и указания заказчика.
Этот файл — единый бриф для всех, кто пишет код сайта.

## Что это и для кого

Сайт-каталог ООО «Ю-ВЕЛО»: аренда, выкуп (покупка) и ремонт электровелосипедов.
Посетители — курьеры и горожане, которым нужен электровелосипед быстро и без сложностей.
Главная задача сайта — заявка: «Арендовать» / «Оставить заявку».

Техника в парке (по фото): Wenbox U2 (чёрный с оранжевым), Wenbox U2 Pro (зелёный с оранжевым),
Strong GS350 (синий с оранжевым).

## Данные-заглушки (важно)

Цены, характеристики, адрес, телефон и мессенджеры пока вымышленные. Все они лежат в
`src/data/*` и `src/lib/site.ts` и помечены `PLACEHOLDER`. Реальные цены позже возьмём с Авито.
Не хардкодь цены, телефоны и адрес в компонентах — только из этих файлов.

## Стек

Next.js 16 (App Router, `cacheComponents: true`), React 19, TypeScript, Tailwind CSS v4,
`motion` (import из `motion/react`), `zod`, `lucide-react`.
ВАЖНО: это Next.js 16 с изменёнными API. Перед использованием незнакомого API читай
`node_modules/next/dist/docs/` (см. `AGENTS.md`). С `cacheComponents` нельзя вызывать
`new Date()`, `Math.random()`, `cookies()` и т.п. в серверном компоненте вне `<Suspense>`.

## Визуальный язык

Палитра взята из фирменной концепции (вывеска и ресепшен: графит, медный свет, рейки).
Все цвета — только через токены Tailwind из `globals.css`, без сырых hex в компонентах.

| Токен (класс) | Значение | Роль |
|---|---|---|
| `graphite-950` | #121110 | самый глубокий фон (подвал) |
| `graphite-900` | #1A1A1A | основной фон |
| `graphite-800` | #232221 | приподнятые поверхности |
| `graphite-700` | #2E2C2A | границы, hover |
| `chalk` | #F2EFEA | основной текст |
| `silver` | #C0C0C0 | вторичный текст |
| `ash` | #8E8A85 | приглушённый текст (не мельче 14px) |
| `copper` | #FF8A2E | акцент, главные кнопки |
| `amber` | #FFB458 | световой акцент, свечение |
| `wood` | #B66A3C | рейки (только блок-«стойка») |

Текст на `copper` — всегда `graphite-900`. Светлых секций нет: сайт тёмный, как интерьер бренда.

Шрифты: заголовки — Unbounded (`font-display`), текст — Onest (`font-sans`).
Заголовки в sentence case, без капса. Unbounded широкий: длинные слова на мобильном
переполняют строку, поэтому используем готовые классы `.h1 .h2 .h3` из `globals.css`.

Фирменные приёмы (их всего три, больше ничего не изобретаем):
1. **Световая линия** — тонкая светящаяся янтарная полоса (`<LedLine />`), как LED-подсветка стойки.
   Отмечает начало секции и важные границы.
2. **Косой срез** — класс `.cut` (угол срезан по диагонали, как торец стойки ресепшен).
   Только для рамок фотографий и ключевых карточек.
3. **Рейки** — класс `.slats` (вертикальные рейки с подсветкой снизу). Только для одного
   блока — финального призыва с формой.

Чего не делаем: градиентные «AI»-пятна, стекло/blur-карточки, эмодзи вместо иконок,
капс-надзаголовки над каждым заголовком, одинаковые закруглённые карточки с тенью,
нумерация 01/02/03 там, где нет последовательности (нумеруем только шаги аренды),
стрелки «→» в тексте кнопок, акцентный цвет на одном слове заголовка.

Радиусы: 6px у кнопок и полей, 4px у карточек. Иконки — `lucide-react`, толщина 1.75.

## Движение

- Hero: одна собранная анимация при загрузке (строки заголовка поднимаются, световая линия прочерчивается).
- Секции: появление при прокрутке через `<Reveal>` — только сдвиг 16px + прозрачность, один раз.
- Интерактив: вкладки (скользящий индикатор), лайтбокс галереи, аккордеон FAQ, состояния формы.
- Hover у кнопок и карточек: 150–200ms. `prefers-reduced-motion` обязателен (в `Reveal` уже учтён).

## Качество

Адаптив 375 / 768 / 1024 / 1440 без горизонтальной прокрутки. Зоны нажатия не меньше 44px.
Видимый focus. Контраст текста не ниже 4.5:1. Фото только через `next/image` с `sizes` и
осмысленным `alt`. Один `<h1>` на страницу. Тексты — простым языком, от лица пользователя,
без канцелярита и рекламных штампов. Язык интерфейса — русский.
